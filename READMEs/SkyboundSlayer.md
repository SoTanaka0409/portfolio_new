## 🎮 ゲーム概要
「SkyboundSlayer」は、3Dアクションにおけるダイナミックな空中戦と、プレイヤーが酔わないカメラワークの実装に挑戦したプロジェクトです。
プレイヤーが直感的に「動かして気持ちいい！」と感じるスピード感と、攻撃を当てる爽快感を極限まで追求しています。

- **Engine**: Unity (バージョンを記載) / Unreal Engine
- **Language**: C# / C++
- **開発人数**: 1人
- **開発期間**: 〇ヶ月

## ✨ プログラマーとしてのこだわり・アピールポイント
- **拡張性の高い状態管理**
  複雑なアクション処理を整理するため、拡張性の高いアーキテクチャ（ステートマシン等）を設計・実装しました。
- **カメラワークと手触り**
  空中での激しい戦闘でもプレイヤーが視認性を失わないよう、カメラの追従処理を工夫しています。
